## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Complete-Gen-Ai-Project.git
```

### 2. Navigate to the Project Directory

```bash
cd Complete-Gen-Ai-Project
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate Virtual Environment

**Windows:**
```bash
.venv\Scripts\activate
```

**macOS / Linux:**
```bash
source .venv/bin/activate
```

### 5. Install Dependencies

Install the Python packages required by the individual scripts.

```bash
pip install -r requirements.txt
```

If a `requirements.txt` file is not present, install the dependencies used by the respective Python script.

### 6. Configure Environment Variables

Add the required API keys to a `.env` file according to the AI provider used in each project.

Example:

```env
GOOGLE_API_KEY=your_google_api_key
GROQ_API_KEY=your_groq_api_key
```

Never upload API keys, passwords, or other sensitive credentials to GitHub.
